What is a Computer?

A Personal Computer (PC) is an electronic device used for learning, working, browsing the internet, programming, gaming, designing, and many other tasks. A computer contains hardware such as the CPU, RAM, storage, motherboard, keyboard, mouse, and monitor. It also runs software like Windows, Microsoft Office, web browsers, and many useful applications.

Learn More

🖥️ CPU

What is a CPU? The CPU is the brain of a computer. It processes instructions, performs calculations, and controls many computer operations. Main functions: - Executes programs and applications. - Performs mathematical calculations. - Processes instructions. - Helps run games and software. Important CPU specifications: - Cores: Processing units inside the CPU. - Threads: Tasks the CPU can handle simultaneously. - Clock speed: How fast the CPU operates, usually measured in GHz. Example: Intel Core i3, Intel Core i5, AMD Ryzen 5.

💾 RAM

What is RAM? RAM is the computer's temporary working memory. It stores information that the CPU needs to access quickly while programs are running. Main functions: - Helps run multiple applications. - Makes switching between programs smoother. - Temporarily stores active program data. - Helps improve multitasking performance. RAM capacities: RAM Typical use 4 GB Basic tasks 8 GB Everyday use 16 GB Programming and multitasking 32 GB Heavy workloads 64 GB Professional workloads Important: RAM is temporary. Its contents are cleared when the computer shuts down.

💽 Storage

What is storage? Storage is where your computer permanently saves files, applications, pictures, videos, and operating system files. There are two common types: HDD (Hard Disk Drive) - Uses spinning magnetic disks. - Usually cheaper for large capacities. - Generally slower than SSDs. SSD (Solid State Drive) - Uses flash memory. - Faster file access. - Faster Windows startup. - No spinning disks. Feature HDD SSD Speed Slower Faster Noise Can make noise Silent Durability More sensitive to shocks More resistant to shocks Price per GB Usually cheaper Usually more expensive

🌐 Internet

What is the Internet? The Internet is a worldwide network that connects computers, phones, servers, and other devices so they can communicate and exchange information. Main uses: - Browsing websites. - Watching YouTube videos. - Sending emails. - Downloading files. - Playing online games. - Communicating with people worldwide. Important Internet specifications: Term Meaning Mbps Internet speed Download Receiving data Upload Sending data Ping Network response time Wi-Fi Wireless network connection Router Connects your devices to a network
